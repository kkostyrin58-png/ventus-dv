# ВЕНТУС ДВ

Демонстрационная версия сайта вентиляции и климатического оборудования: главная, семь категорий, поиск направлений и переходы с анимацией вентилятора. Товары, цены, заказы и админка пока не реализованы.

## Онлайн-просмотр

После включения GitHub Pages: https://kkostyrin58-png.github.io/ventus-dv/

В Settings → Pages выберите **Deploy from a branch**, ветку **main**, папку **/docs**, затем Save. Папка docs содержит готовые страницы и ассеты, а не исходные материалы аудита.

## Локальный запуск

Нужен Node.js 24+. Внешних пакетов нет.

```sh
node server.mjs
```

Сайт откроется по http://127.0.0.1:4182. Категории читаются из SQLite. Локальная база создаётся из sql/catalog.sql и не включается в Git.

## Проверка и сборка

```sh
node --test tests/catalog.test.mjs tests/pages.test.mjs
node scripts/build-pages.mjs
```

Статическая версия появляется в dist/. Для обновления онлайн-демо перенесите содержимое dist/ в docs/ и отправьте изменения в main. SQL остаётся источником начальных данных; GitHub Pages обслуживает HTML, CSS, JavaScript и JSON без серверной базы данных. Переменная PAGES_BASE меняет базовый путь (по умолчанию /ventus-dv/).

В public/ находится интерфейс; scripts/ содержит сборку; sql/ — схему и начальные категории; tests/ — проверки сервера, данных и статической публикации. Исходный Node/SQLite-режим сохранён.

Интерьер на главной — AI-визуализация, а не фотография выполненного объекта. Иконки категорий условные и не изображают конкретные модели товаров. Демоверсия имеет noindex и не предназначена для приёма реальных заказов.
